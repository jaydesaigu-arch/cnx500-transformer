# CNX 500 CPU experiment specification

Scope: NSE:CNX500 index only. Predictions after a completed daily bar for 3, 5 and 10 observed trading sessions. All five class probabilities are returned; a neutral label is not an abstention or low confidence label.

Input: TradingView TVRemix get_ohlcv, 1D, count=5000; retrieved 2026-10-03. Full reconciliation with official published NSE index history found 11 omitted sessions and 14 shared dates with OHLC discrepancies beyond 0.011 points. Training uses 5,011 published index sessions: official OHLC on shape-valid dates, validated original TV OHLC on two flagged official-inconsistent dates, and TV volume where available. Twelve shared dates are materially corrected to official OHLC. Missing volume on official-only sessions is zero-as-unavailable. Original TV CSV and official raw responses stay local and unchanged. Canonical timestamps are 09:15 Asia/Kolkata session-date anchors, not claimed historical special-session opening times. No synthetic price bars or forward filling. Data provenance and every exception are recorded in reports/data_reconciliation.json. Connector volume remains a provider field with unverified aggregation semantics and discrepancies from official daily archive volume.

Targets: log(C[t+h]/C[t]) / (past 60-session daily log-return sample standard deviation * sqrt(h)), with a 1e-6 denominator volatility floor. Fixed bins: z < -1 Strong Bearish; -1 <= z < -0.25 Bearish; -0.25 <= z <= 0.25 Neutral; 0.25 < z <= 1 Bullish; z > 1 Strong Bullish. These definitions measure endpoint movement, not the intervening path.

Contexts: 20, 60, 120, 252 sessions. Compare price-only and price-plus-provider-volume. Use the same eligible prediction dates across all contexts. Features are past/current OHLC transformations, rolling returns/volatility and optionally relative volume and missing-volume flag. Fit feature scaling only on fitting data; no full-history normalization.

Models: empirical class priors, logistic regression, histogram gradient boosting, small shared multi-horizon MLP, compact causal patch Transformer, identical Transformer with causal next-patch pretraining. Patch size 4, embedding 32, two layers, four heads, feedforward 64. Next-patch pretraining is continuous-feature self-supervision, not a pretrained text LLM or discrete-token foundation model. Never expose the next patch through attention when predicting it.

Development outer folds: 2016-01-01 through 2018-12-31; 2019-01-01 through 2021-12-31; 2022-01-01 through 2024-09-30. For each outer fold, training origins and their full 10-session labels must precede its first evaluation origin. Reserve approximately the last 252 eligible historical origins before the outer evaluation as inner tuning data, purge crossing labels, select neural epochs there, then refit on the entire permitted prefix for that fixed epoch count. Pretraining and scaler fitting obey the same chronology. Internal tuning labels must mature before outer evaluation.

Untouched final holdout: origins >= 2024-10-01 whose 10-session targets are available. Freeze one best baseline configuration and one best neural configuration using development macro-F1 before computing this final test. Archive selection before opening test results. Do not claim walk-forward retuning during the final holdout: final test weights are static. Only after recording test results, refit selected configurations on all matured history for current research predictions; current refit metrics are not holdout metrics.

Metrics: per-horizon macro-F1 over all five classes, balanced accuracy, accuracy, log loss, multiclass Brier score, expected calibration error, mean absolute ordinal error, and extreme reversal frequency; class supports and 5x5 confusion matrices. Report raw probabilities explicitly as uncalibrated. Average development macro-F1 equally across folds and horizons. Include per-year and rolling-period evidence where supported; overlapping targets are dependent observations.

Publication: source, synthetic fixtures, configuration, data provenance and research report can be versioned. Exclude real raw data, date-level derived datasets/predictions, model weights and secrets until applicable redistribution/derived-output rights are confirmed. No trading execution, automatic updates, purchases, paid services or external messaging. No profitability claims. No final financial judgment delegated to Hermes.

Implementation acceptance details: all contexts/models/feature variants share origins with 252 valid feature days and fully matured 10-session labels. Daily features include the completed return ending at t. Volatility is floored at 1e-6 before multiplying by sqrt(h). Inner tuning is the last exactly 252 eligible prefix origins; fitting origins must end their labels strictly before the first tuning origin. Inner pretraining/scaling use only fitting origins and earlier feature history. Outer refitting repeats scaling and pretraining using the entire purged permitted prefix. Final test uses the identical purging rule at 2024-10-01 and the median selected configuration's development best-epoch counts, with no holdout tuning. CPU tensors, four compute threads, one interop thread, batch 128, maximum 20 supervised epochs, patience four, four pretraining epochs. MLP sizes are summary feature dimension -> 64 -> 32 -> 15. Transformer patches flatten four adjacent observed days; pretraining position j predicts patch j+1 with causal attention. Candidate space is one majority baseline plus five learned model types x four contexts x two feature variants = 41 configurations; three outer folds = 123 fits, plus inner epoch selection/refits for neural models. Seed 42. Exact ties rank by smaller log loss, shorter context, price-only, then model name. Additional development seeds, if run, are diagnostic only and cannot change selection. Metric details are executable in metrics.py: five-class macro-F1 missing classes score zero; balanced accuracy averages present true classes; lowest ordinal wins probability ties; Brier is mean of sum of squared class errors; ECE uses ten equal-width max-probability bins; ordinal positions are 0 through 4; extreme reversal means 0 versus 4. Secrets are always excluded from publication regardless of data rights; content exclusions override permitted document categories.

Limitations: session order is reconciled against official published Nifty 500 history, not an independent reconstruction of all exchange session rules. Two official-inconsistent OHLC dates retain validated TV data. Provider-volume semantics remain unverified. Single index is a small, correlated dataset. Bounds are research choices. Only one seed in the initial CPU sweep; selected neural model will receive additional seed stability checks on development data if time permits. A failure to beat baselines is a valid result. The audit initially computed full-history aggregate label counts before selection; no holdout model metrics or date-level labels were inspected or used in configuration selection, and subsequent audit class counts are restricted to development.
